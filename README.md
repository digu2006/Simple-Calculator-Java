 # Simple Calculator Using Java Swing

## Project Description
This project is a Simple Calculator developed using Java Swing GUI. It performs basic arithmetic operations through a graphical user interface.

## Technologies Used
- Java
- Java Swing
- AWT
- NetBeans / IntelliJ IDEA

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Decimal calculations
- Clear button
- User-friendly GUI
- Division by zero handling

## Project Files
- `SimpleCalculator.java` – Java source code.
- `Calculator_Output.pdf` – Application output screenshots.
- `README.md` – Project documentation.

## How to Run
1. Download or clone this repository.
2. Open the project in NetBeans or IntelliJ IDEA.
3. Open `SimpleCalculator.java`.
4. Run the main method.
5. The calculator GUI will open.
